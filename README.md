PSNextSpriteEditor
==============

Simple sprite editor for [PuzzleScript Next](https://puzzlescriptnext.polyomino.com) games.

The editor is all HTML5/CSS-based, so it should run in any HTML5-compatible browser. 

This code is provided as is, with no support. If you make improvements and would like to share, please send me a pull request.

Based on https://github.com/otrain13/PSSpriteEditor by Owen Gross
